What I fix

Every bottleneck, tracked down and removed.

I don't apply a generic checklist. I audit your specific store, find what's actually slowing it down, and fix exactly those things.

📦

App audit & cleanup

I go through every installed app and find which ones are firing scripts on pages that don't need them. You keep the functionality, lose the weight.

🖼️

Image optimization

Images are almost always the #1 culprit. I compress, convert to WebP, implement lazy loading, and make sure the right size loads on the right device.

⚡

JavaScript & CSS cleanup

Unused theme code, render-blocking scripts, duplicate libraries — I strip it all. Your theme looks identical, loads faster.

📊

Core Web Vitals (LCP, CLS, INP)

These are Google's metrics that directly affect both rankings and user experience. I fix LCP, eliminate layout shifts, and improve interactivity.

📱

Mobile-first performance

Mobile is where most of your traffic is and where Shopify stores score worst. I specifically target mobile load times because that's where sales are lost.

🔡

Font & third-party script loading

Review widgets, chat scripts, pixel tags — all of these add to your page weight. I delay, defer, or consolidate them so they don't block your store from loading.
